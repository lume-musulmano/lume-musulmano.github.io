# Lume Musulmano

Sito web di **Lume Musulmano** — corsi in italiano per comprendere il Corano,
sviluppare pensiero critico e intelligenza emotiva, l'arte della da'wah e la
formazione intellettuale islamica.

Sito statico (HTML, CSS, JavaScript), senza dipendenze da build.

## Struttura
- `index.html` — home page
- `corsi.html` — catalogo dei corsi
- `chi-siamo.html`, `contatti.html` — pagine istituzionali
- pagine dei singoli corsi (es. `pensiero-critico.html`, `escatologia.html`, …)
- `styles.css`, `script.js` — stile e interazioni
- `cover-*.jpg`, `logo-*.png` — immagini

## Pubblicazione (GitHub Pages)
Impostazioni del repository → **Pages** → Branch: `main` / cartella `/root` → Save.
Il sito sarà online su `https://<utente>.github.io/<nome-repo>/`.
